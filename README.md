# 🤖 My_Jarvis — AI-Powered Voice Assistant

### Just A Rather Very Intelligent System

**My_Jarvis** is an AI-powered desktop voice assistant developed using Python, Ollama, and Windows Automation. It understands voice commands, provides intelligent responses, and automates everyday computer tasks through a futuristic graphical interface.

![Python](https://img.shields.io/badge/Python-3.11-blue)
![AI](https://img.shields.io/badge/AI-Ollama-purple)
![Platform](https://img.shields.io/badge/Platform-Windows-green)

---

## 🚀 Features

* 🎙️ **Voice Recognition** — Understands and processes voice commands.
* 🧠 **AI Conversations** — Generates responses using Ollama and Llama 3.2.
* 🖥️ **Application Control** — Opens Windows applications.
* 🌐 **Web Automation** — Google searches, YouTube, and website navigation.
* 📱 **WhatsApp Integration** — Opens WhatsApp Web and prepares messages.
* 🧮 **Smart Calculator** — Performs mathematical calculations.
* 🖱️ **Desktop Automation** — Mouse and keyboard control.
* 📝 **Notes & Memory** — Saves and retrieves information.
* 📁 **File Management** — Searches for files and opens folders.
* 🔊 **System Controls** — Screenshots and volume adjustment.
* ✨ **Interactive Dashboard** — Futuristic GUI using CustomTkinter.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/Diya9867/My_Jarvis.git
cd My_Jarvis
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Install Ollama**

Install Ollama from its official website and ensure it is running.

**4. Download the AI model**

```bash
ollama pull llama3.2:1b
```

**5. Run JARVIS**

```bash
python jarvis.py
```

> **Requirements:** Windows 10/11, Python 3.11, a working microphone, and Ollama.
